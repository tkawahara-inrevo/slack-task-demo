# バーチャルオフィス インフラ・コスト試算

## 1. インフラ構成図

```
ap-northeast-1 (東京リージョン)
┌─────────────────────────────────────────────┐
│ AWS Lightsail                               │
│  ┌─────────────────────────────┐           │
│  │ app instance ($20/月)        │           │
│  │  - Express + Socket.IO       │           │
│  │  - 位置同期 / API / Auth     │           │
│  └─────────────────────────────┘           │
│  ┌─────────────────────────────┐           │
│  │ media instance ($40-80/月)   │           │
│  │  - LiveKit SFU (音声/映像)   │           │
│  │  - Coturn (TURN/NAT越え)     │           │
│  └─────────────────────────────┘           │
│  ┌─────────────────────────────┐           │
│  │ Managed PostgreSQL ($15/月)  │           │
│  │  - ユーザー/マップ/状態保存  │           │
│  └─────────────────────────────┘           │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ AWS S3 (US East or Tokyo)                   │
│  - 画像 / ファイル / 録音 / アバター         │
│  - 1日週次自動ライフサイクル                 │
└─────────────────────────────────────────────┘

外部連携:
- TaskHub (既存 us-east-1) ←→ HTTPS API
- Slack OAuth                ←→ 認証
- Google OAuth (既存)        ←→ オプション認証
```

## 3. ランニングコスト（月額）

### 標準構成（同接 200人想定）

| 項目 | 月額 (USD) | 月額 (JPY概算) | 備考 |
|---|---|---|---|
| Lightsail app instance | $20 | **¥3,000** | 2vCPU / 4GB / 3TB帯域 |
| Lightsail media (SFU) | $40 | **¥6,000** | 4vCPU / 8GB / 4TB帯域 |
| Lightsail Managed PostgreSQL | $15 | **¥2,250** | Standard プラン 1GB |
| AWS S3（標準） | $3〜20 | **¥500〜3,000** | 使用量次第 |
| Lightsail スナップショット | $5 | **¥750** | 自動バックアップ |
| **小計** | **$83〜103** | **¥12,500〜15,000/月** | |

### 拡張時（ピーク同接 200人 + 動画ヘビーユース）

| 項目 | 月額 (JPY) |
|---|---|
| Lightsail media を $80 プランにアップ | ¥9,000（差額+¥3k） |
| S3 容量増加 | ¥3,000〜5,000 |
| **拡張時合計** | **¥18,000〜25,000/月** |

### 採用イベント等で一時的に増強する場合

- 媒体追加 SFU 1台（イベント日のみ）: 日割り ¥300/日 程度
- 月数日のスポット利用なら +¥1,000〜3,000/月

## 4. 年間コスト比較

| サービス | 年間費用 | 機能 |
|---|---|---|
| **現状: Metalife** | **¥500,000** | バーチャルオフィス標準機能 |
| **自社開発（標準構成）** | **¥150,000〜180,000** | カスタマイズ自由 + Pochi連携 |
| **自社開発（拡張時）** | **¥220,000〜300,000** | 200人ヘビーユース対応 |

**年間 ¥200,000〜350,000 のコスト削減** + **自社プロダクトとして拡張可能**

---

## 5. 想定外の追加コスト要因

| 要因 | 月額影響 |
|---|---|
| 録音機能を本格運用（毎日録音保管） | +¥3,000〜10,000（S3 ストレージ増） |
| 採用イベントで外部参加者 100名 一時的 | +¥5,000〜10,000（SFU 一時増強） |
| 監視サービス（Sentry有料、Datadog）導入 | +¥3,000〜15,000 |
| マネージド SFU (LiveKit Cloud 等) に切替 | +¥350,000〜600,000 |

※マネージドSFUは便利だが、自社運用と比べて10倍以上高くなるため非推奨

## 7. 結論

- **インフラ初期費用**: ¥10,000〜33,000（マップ素材次第、ほぼ無料も可能）
- **ランニング月額**: ¥12,500〜25,000
- **年額**: ¥150,000〜300,000
- **Metalife 比 削減効果**: 年 ¥200,000〜350,000
- **拡張性**: Pochi 深連携、自社採用イベント、社内勉強会等の独自ニーズに自由対応可
