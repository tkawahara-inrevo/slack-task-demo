# TaskHub 機能・仕様まとめ

> 最終更新: 2026-05-20  
> システム: INREVO 社内業務管理システム（Slack Bot + Webダッシュボード）

---

## 全体構成

```
TaskHub
├── 社内ポータル系（全社向け）
│   ├── ホーム（タスク・メンション・予定・チーム稼働）
│   ├── 業務ガント
│   ├── WF（Slackワークフロー）
│   ├── 分析
│   ├── チーム設定
│   └── Corp管理（採用テスト・勤怠・ランキング）
└── ヒトトレ系（RPO採用代行事業向け）
    ├── CRM（顧客・商談管理）
    ├── リード管理
    ├── 案件管理（RPO）
    └── 法務
```

## 社内ポータル系

### ホーム画面

**URL**: `/`

| セクション | 内容 |
|-----------|------|
| 勤怠ウィジェット | 出退勤状況・チーム稼働ボタン |
| 今日の予定 | Googleカレンダー連携 |
| マイタスク | 自分に割り当てられたアクティブタスク（カードグリッド） |
| 未読メンション | Slackメンション一覧（48時間以内、既読管理付き） |
| チームのこと | 期限切れタスクのアラート |

- **ポップアップ**: タスク一覧を別ウィンドウで表示（タスクバーバッジ対応）
- **マイタスクバッジ**: 期限当日・期限切れのタスク数をタスクバーアイコンに表示
- **チーム稼働モーダル**: チームメンバーの稼働状況をモーダルで表示
- **ダークモード**: ヘッダーのトグルで切り替え（localStorage永続化）

### Corp管理

**URL**: `/admin`

管理者・人事・ITロール向け機能。

#### 採用テスト管理（実技テスト）

**URL**: `/admin/recruitment`

| 機能 | 内容 |
|------|------|
| 候補者登録 | 氏名・メールアドレスで登録 |
| テスト送信 | GoogleスプレッドシートをGAS経由で送付 |
| 予約送信 | 日時指定で自動送信（デフォルト3日後09:00） |
| 採点 | GASポーラー（1分間隔）で自動採点 |
| ステータス管理 | 未送信/予約済み/送信済/完了/エラー |
| スプシ取り込み | スプレッドシートから候補者一括インポート |

**テストシート仕様**（GAS）
- B30: スクリーンショット確認チェックボックス（新規シートのみ）
- B31: 提出チェックボックス
- C19: タイピングスコア入力（0〜1000）
- 条件付き書式: 条件未達で赤表示、OK時に緑表示
- ポーラー: 1分ごとにB31チェックを検知し採点・通知

**採点方式**（10点満点）
- 問1〜10: 各1点
- 問13（タイピング）: 参考指標のみ（採点対象外）
- 問14: 人事確認（自動採点なし）

#### ランキング

**URL**: `/ranking`（Corp内・分析用）

Slackチャンネルの投稿数ランキングを集計。

| カテゴリ | 内容 |
|---------|------|
| 雑談 | 雑談チャンネルへの投稿数（トップレベル＋返信を件数分カウント） |
| 日報返信（合算） | 出退勤日報への返信数合計 |
| 出勤日報返信 | 出勤日報スレッドへの返信数 |
| 退勤日報返信 | 退勤日報スレッドへの返信数 |
| 全部合算 | 上記すべての合計 |

- 同一スレッドへの複数投稿はそれぞれカウント
- 集計対象期間・上位件数は可変

### CRM（顧客・商談管理）

**URL**: `/crm`

#### ダッシュボード

| KPIカード | 内容 |
|----------|------|
| 入金確定 | 今月の入金確定額（kintone App170） |
| 今月受注 | 今月受注件数・金額 |
| ほぼ確実 | ヨミ A 70%・S 90% の案件 |
| 多分いける | ヨミ B 50%・C 30% の案件 |
| 初回商談 | 今月の初回商談件数 |

- KPIカードクリックでドリルダウン表示
- 担当者別売上・インセン集計
- 入金推移チャート（月別）
- 最終kintone同期時刻の表示
- 期別・月別の切り替え

#### 案件一覧・詳細

- 顧客（Customer）と商談（Deal）の管理
- ヨミ管理: `アポ化前 → アポ化済商談前 → E〜S → 受注/失注/見送り`
- ヨミ変更で自動的にステータス更新（`won/lost/dormant`）
- **受注になるとRPO案件が自動生成**（担当チーム未割当で作成）
- 活動履歴・次のアクション管理
- BANTヒアリング項目

#### kintone連携

- **App102**（案件）: 30分ごと自動同期 → `kintone_cache` → `deals`
  - ヨミの短縮形に正規化（括弧付き文字列を除去）
  - 会社名でマッチングして deals を更新
  - `status`（won/lost/dormant/active）を自動導出
- **App170**（入金）: 30分ごと自動同期 → `kintone_cache` → `kintone_payments`
  - 手動同期ボタンも提供

### 案件管理（RPO）

**URL**: `/rpo`

#### 案件一覧（Kanbanビュー）

フェーズ別にクライアント案件を管理。

| フェーズ | 内容 |
|---------|------|
| CR | 初回インタビュー |
| ST/AN | 分析・媒体調査 |
| DR | 最終判断・承認 |
| CS/OP | 採用活動中 |

- **未割当セクション**: CRMで受注になって自動生成された案件（チーム未割当）
- フェーズドロップダウンで即座に変更
- チェックリスト進捗バーをカードに表示
- 担当チーム割り当てドロップダウン

#### 案件詳細

**タブ構成**

| タブ | 内容 |
|-----|------|
| ダッシュボード | フェーズチェックリスト・CRM連携情報・プロジェクト概要・売上収益 |
| KPI | 採用目標・ファネル分析 |
| 媒体・予算管理 | 求人媒体・予算・掲載期間管理 |
| 応募者 | 応募者一覧・ファネル管理 |
| タスク | 案件タスク |
| 書類 | ドキュメント管理 |
| 歩留まり | 採用ファネル可視化 |

**ダッシュボードタブの特徴**
- **フェーズチェックリスト**: 各フェーズのToDo（4項目）、完了状況をバーで表示
- **CRM連携情報パネル**: 紐づくCRM案件の受注日・担当営業・受注金額等を表示、プロジェクト概要への同期ボタン
- **同一顧客の関連案件**: 他のRPO案件・CRM商談を表示（クリックで遷移）

**フェーズチェックリスト項目**

| フェーズ | チェック項目 |
|---------|------------|
| CR | 初回インタビュー実施済み / ヒアリング内容記録 / カルテ記入依頼 / 採用戦略合意 |
| ST/AN | SWOT/4C分析完了 / 媒体調査完了 / 価格交渉完了 / 費用感作成 |
| DR | 媒体最終決定 / 代表承認 / STリーダー承認 / CS引き継ぎ |
| CS/OP | 求人票作成・掲載 / 応募者管理開始 / 進捗報告 / 内定通知 |

#### サマリー（上長向けダッシュボード）

**URL**: `/rpo/summary`

- **フェーズ別パイプライン**: 各フェーズの案件数と案件名一覧
- **滞留アラート**: 7日以上更新がない案件を赤表示
- **担当者別集計**: 担当者ごとの案件数・フェーズ内訳
- 進行中案件テーブル（フェーズ・HR担当・最終更新日付き）
- 終了済み案件（折りたたみ）

#### 新規案件作成

- **CRM受注案件から検索**（kintoneではなく新システムから）
- 選択すると担当営業・受注日・受注金額・採用目標を自動マッピング
- すでにRPO案件が存在する場合は「案件あり」と表示
- CRMに該当なしでも手動で企業名を入力して作成可能

### 法務（案件進捗管理）

**URL**: `/legal`（ヒトトレ配下）

| 機能 | 内容 |
|------|------|
| 案件一覧 | 対応中/全件タブ、検索、ソート |
| 新規作成・削除 | ワンクリックで作成 |
| 2日未更新アラート | バッジ表示＋フィルタリング |
| 案件詳細 | NA日・優先度・担当・ボール・結果・各テキストフィールド |
| 対応履歴 | 日付・種別・内容を追加/削除 |
| 議事録履歴 | 日付・種別・内容を追加/削除 |

**案件フィールド一覧**

| フィールド | 内容 |
|-----------|------|
| 案件名（企業名） | 自由入力 |
| NA日 | 期限日 |
| 対応開始日 | 開始日 |
| 優先度 | 高/中/低 |
| 担当 | 担当者名 |
| ボール | 現在誰が持っているか |
| NA処理台帳番号 | 台帳管理番号 |
| 問題箇所（1行） | 問題の要約 |
| 問題該当箇所詳細 | 詳細説明 |
| 契約書該当箇所 | 第〇条など |
| 方向性・対応方針 | 交渉・修正方針 |
| スレッドURL | Slackスレッドリンク |
| 結果・ステータス | 対応中/Close/完了など |

## 技術スタック

| 要素 | 内容 |
|------|------|
| フロントエンド | React + Vite (`web/src/`) |
| バックエンド | Node.js + Express (`src/features/`) |
| DB | PostgreSQL（DB名: `slacktask`） |
| Slack | Bolt.js |
| デプロイ | AWS Lightsail `3.222.101.208` / PM2 |
| 外部連携 | kintone (App102: 案件, App170: 入金) |
| 勤怠連携 | HRMOS勤怠 API |

## 主要DBテーブル

| テーブル | 用途 |
|---------|------|
| `customers` | CRM顧客 |
| `deals` | CRM商談（yomi/status/order_date等） |
| `deal_activities` | 活動履歴 |
| `kintone_cache` | kintone同期キャッシュ |
| `kintone_payments` | App170入金データ |
| `rpo_clients` | RPO案件（phase付き） |
| `rpo_applicants` | RPO応募者 |
| `recruitment_candidates` | 自社採用テスト候補者 |
| `recruitment_scheduled_sends` | 採用テスト予約送信 |
| `legal_cases` | 法務案件 |
| `workload_items` | 業務ガントアイテム |
| `user_mentions` | Slackメンション |
| `tasks` | タスク全般 |

## ロール権限

`authWithRole` で自動判定:
- `admin`: 全機能アクセス可
- `corp`: Corporateチーム
- `it`: ITチーム
- `personnel`: Personnelチーム（採用管理権限あり）
